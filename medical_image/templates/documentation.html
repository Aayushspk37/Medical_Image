X-HViT Documentation

Welcome to the official documentation for X-HViT — Explainable Hybrid Vision Transformer for medical image classification. This guide covers architecture, API usage, and integration.

Version: X-HViT v1.0 · February 2026 · BCE Final Year Project · United Technical College

What is X-HViT?

X-HViT is a hybrid deep learning model that combines Convolutional Neural Networks (CNN) for local spatial feature extraction with Vision Transformers (ViT) for global context modeling, trained on 28,000+ medical images across four imaging modalities.

  • Multi-modal: CT, MRI, X-ray, Microscopic imaging
  • Dual XAI: Grad-CAM + Transformer Attention Maps
  • Django REST API backend with PDF report generation
  • 95%+ target classification accuracy via K-fold validation

Installation

# Clone the repository git clone https://github.com/utc/xhvit.git cd xhvit # Create virtual environment python -m venv venv source venv/bin/activate # Windows: venv\Scriptsctivate # Install dependencies pip install -r requirements.txt # Run migrations python manage.py migrate # Start development server python manage.py runserver

Quick Start

Run a diagnosis programmatically using the Python client:

# Basic usage from xhvit import XHViTModel model = XHViTModel.load_pretrained('xhvit-v1.0') result = model.predict('brain_scan.jpg', modality='mri') print(result.disease) # "Glioma Tumor" print(result.confidence) # 0.947 print(result.probabilities) # {'Glioma': 0.947, 'Meningioma': 0.031, ...} result.gradcam.save('heatmap.png')
